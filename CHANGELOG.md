## 1.0.0 - 2026-10-15

### OpenGenset v1.0.0

Official initial release of OpenGenset - An open platform for B2B industrial machinery commerce, dynamic quotation cockpits, and intelligent IoT generator telemetry monitoring.

#### Highlights:

- **NestJS 12 Backend API Server** with Drizzle ORM, PostgreSQL 18, and Redis 8.
- **Next.js 16 Backoffice Admin Portal** with dynamic quotation workflow, warehouse inventory, and dark mode support.
- **Next.js 16 Customer Storefront** with faceted search, spec sheets, and B2B RFQ submission.
- **Industrial Minimalist Brand Identity** with Titanium & Slate monochrome assets.
- **Automated SemVer Release Pipeline** with Google Release Please.
